# Leonida Trophy Atlas

[![Reward](https://make.fun/badge/gta6-trophy-guide-01/reward.svg)](https://make.fun/bounty/gta6-trophy-guide-01)

An original, offline-first guide and checklist for all 55 Grand Theft Auto VI PlayStation 5 trophies. The atlas keeps the official trophy names, descriptions and grades intact, then adds practical notes, sources, a five-stage route to Platinum and an early warning for the potentially missable meditation trophy.

## Features

- Progress saved in your browser, with JSON export and import.
- Search and filters for grade, trophy type, missables and earned status.
- Story spoiler mode hides unearned hidden trophy names and descriptions.
- Expandable trophy guides with sources beside each set of field notes.
- A roadmap, missable warning, progress bar and grade totals.
- No external scripts, fonts, images or runtime requests.

## Run offline

From the repository root, start the static server:

```sh
node serve.ts
```

Open `http://localhost:8080` in a browser. The app and its data are served from this repository; after the local files are available, it makes no network requests.
