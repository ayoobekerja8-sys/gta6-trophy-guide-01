# Leonida Trophy Atlas

An offline-first GTA VI PS5 trophy tracker, roadmap, and field guide. All app assets are local; progress stays in your browser and can be exported as JSON.

## Run

Use Node 22:

```sh
node serve.ts
```

Then open http://localhost:8080. The app runs without network requests.
